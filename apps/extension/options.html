Planarus extension options

Where Planarus runs

The address you open Planarus at. Leave blank for http://localhost:5173. For a shared install on your network, put the LAN address here — the app's account menu has a copy LAN address button that gives you the exact value. This only decides which tab gets opened, so the browser asks for no permission and the extension still makes no request of its own.

Pending-approval badge (optional)

Shows how many approvals are waiting for you, in the toolbar, without opening Planarus. This is the one part of the extension that holds a credential and calls the API — select-to-capture holds neither. Use a read-only key, issued from Planarus's Settings → API Clients. Leave both fields blank to keep the badge off.
