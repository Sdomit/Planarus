# Support

Planarus is a pre-1.0, local-first project. Support is best-effort; no service
level, uptime, or response-time commitment is offered.

- For reproducible bugs and feature ideas, use GitHub Issues with clear steps,
  expected behavior, and actual behavior.
- For setup, read the guides under `docs/guide/` and `docs/dev/setup.md` first.
- For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and never
  include credentials, database files, API keys, or private paths in a public
  issue.

If the external API, LAN mode, cloud storage, or a tunnel is enabled locally,
include only the documented configuration category and the behavior observed;
remove endpoint hostnames, tokens, and customer information.
